Git e GitHub [20 Horas]

Domine o controle de versões e colabore como um profissional

Na jornada da programação, dominar Git e GitHub é essencial. Com essas ferramentas você poderá versionar seus projetos, colaborar com equipes e manter um histórico seguro de alterações.

Você aprenderá desde os fundamentos até fluxos reais de trabalho com branches, merges e pull requests.

Ideal para iniciantes e também para quem deseja organizar melhor seus projetos profissionais.
